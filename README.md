## 🎯 Why This Is Unique

### Emoji-Rich Format

Every response can be made visual and friendly.

Before:
- Summarize this content
- Point 1
- Point 2

After:
- 📚 SUMMARIZE THIS CONTENT.
- 🎯 In Short.
- 📌 Key Points.
- 💡 Easy to understand.

### Perfect Alignment

The design uses clear spacing, headings, and grouped sections. This makes the file easier to scan for beginners.

### Beginner-Friendly

The goal is to avoid hard words and keep answers simple. Even technical topics can be explained in easy language.

### 100 Operations

This project is bigger than a normal study assistant. It gives a wide learning system for many subjects and use cases.

### Copy-Paste Ready Prompts

Each operation is designed to be used directly inside the app. The structure is made for consistency and clarity.

## 📦 Installation

### Prerequisites

- Java 17+
- Spring Boot 3.2+
- Maven 3.8+
- Groq API key

### Setup Steps

1. Download the project.
2. Add your Groq API key as an environment variable.
3. Set the application name and Groq URL in configuration.
4. Run the Spring Boot app.
5. Send requests to the API.

***

## 🚀 Quick Start

### API Endpoint

`POST /api/assist`

### Example Request Fields

- content
- operation
- researchGoal
- ProgrammingLanguage
- subject
- studyTopic

### Example Use

You can send a topic like “OOP” with the operation “summarize” and get a beginner-friendly answer back.

***

## 🧩 How It Works

1. A request comes in.
2. The controller receives it.
3. The service builds the prompt.
4. The prompt is sent to Groq.
5. The AI response is extracted and returned.

***

## 🛠️ API Endpoints

| Endpoint | Method | Purpose |
|---|---|---|
| /api/assist | POST | Send request and get AI result |
| /api/operations | GET | List all 100 operations |
